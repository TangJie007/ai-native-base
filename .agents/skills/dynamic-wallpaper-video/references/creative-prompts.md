# Creative Prompts (Wallpaper-Safe)

Prompts for AI image/video tools. Keep them **ambient, loopable, text-free**.

## Universal negative / avoid block

Append (adapt to tool syntax):

```text
no text, no letters, no watermark, no logo, no UI, no HUD, no subtitles,
no timeline, no progress bar, no frame border, no collage, no split screen,
no fast camera shake, no jump cuts, no flashing strobe, no horror jumpscare,
no readable signs, no celebrity face close-up
```

## Structure

```text
[subject], [environment], [lighting], [motion], [camera], [mood], [style],
seamless looping motion, locked camera, slow ambient movement, desktop wallpaper
```

## Motion phrases that loop well

- gentle rain on window glass, soft droplets trailing, city bokeh beyond
- slow drifting clouds over mountains, golden hour, subtle light change
- candle flame and rising smoke, dark cozy room, shallow depth of field
- neon reflections shimmering on wet street, cyberpunk alley, slow steam
- dust particles floating in a sunbeam, quiet loft interior
- northern lights slow wave over snowfield, long exposure feel
- aquarium bubbles and slow fish (avoid sudden direction changes)
- paper wind chime swaying, soft breeze, fixed wide shot

## Motion phrases to avoid

- dramatic orbiting drone shot
- character walking through a story beat
- explosion / rapid transform morph
- countdown / clock faces with moving hands (seam hell unless period matches)
- heavy handheld camera

## Example prompts

### Rainy window (1080p desktop)

```text
Cozy apartment window on a rainy night, soft rain streaks on glass,
out-of-focus warm city lights beyond, condensation details, calm mood,
locked camera, slow continuous rain loop, cinematic color grade,
photorealistic, no people, no text, seamless ambient wallpaper motion
```

### Ink wash mountains

```text
Traditional ink-wash mountain landscape, mist slowly flowing through valleys,
minimal black ink on rice-paper tone, serene scholarly mood,
locked wide composition, very slow mist drift suitable for seamless loop,
no calligraphy text, no seals, no UI
```

### Soft abstract light

```text
Abstract soft gradient aurora of teal and deep navy, slow morphing light bands,
grain subtle, meditative, locked frame, seamless looping motion,
no shapes that look like logos or letters
```

## Still → video prompt add-ons

When animating a user still:

```text
Animate this exact image, preserve composition and character identity,
add only subtle motion: [rain / parallax / light flicker / steam],
locked camera, no reframing, no new objects, seamless loop
```

## Duration hints for generators

Ask for **10–16 seconds**, **24 or 30 fps**, **16:9** (or phone 9:16).  
If the tool maxes at 5s, generate multiple takes of the same prompt and plan a dissolve/boomerang in post — or use Path B.

## Style consistency

One wallpaper = one style. Do not mix anime character sheet + photoreal city unless brief says so. Desktop pets and UI chrome do not belong in wallpaper plates.
